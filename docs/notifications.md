# 배정 알림

## 1. QR 내 자리 확인 (시연 모드와 서버 모드 모두)

배정이 끝나면 키오스크에 QR이 뜹니다. 주소는 `me.html?s=좌석&n=이름&d=날짜&t=시각` 형태이고, 휴대폰에서 열면 자리 번호와 배치도에 내 자리가 표시됩니다. 서버나 계정이 필요 없어서 시연 때 바로 쓸 수 있습니다.

서버 모드에서 학생 휴대폰이 학교 와이파이에 없으면 UNO Q 주소로 접속할 수 없으니, 감독 화면 설정의 "내 자리 확인 주소"에 GitHub Pages 주소를 넣어 두면 QR이 그쪽으로 열립니다. `me.html`은 서버 없이 주소에 담긴 정보만으로 화면을 그립니다.

## 2. 카카오톡 봇 연동 (서버 모드)

서버는 배정과 이동이 생길 때마다 알림 목록에 쌓습니다.

```
GET /api/events?since=2026-11-04T10:00:00.000Z&token=EVENTS_TOKEN
```

```json
{ "ok": true, "events": [
  { "at": "2026-11-04T10:02:11.120Z", "type": "assign", "id": "10101", "name": "한지유", "seat": 20,
    "message": "[자기주도학습실] 한지유 학생, 오늘 야간자율학습 좌석은 20번입니다." }
] }
```

봇은 마지막으로 받은 `at`을 기억해 두고 몇 초마다 `since`에 넣어 새 알림만 가져간 뒤 `message`를 보내면 됩니다. 봇이 서버에 요청을 보내는 방식이라 봇 쪽에 외부에서 접속할 주소를 열 필요가 없습니다.

카카오톡 봇은 봇 계정이 들어가 있는 방에만 보낼 수 있습니다. 그래서 학생 개인에게 보내려면 학생마다 봇과 1:1 방이 있어야 하고, 현실적으로는 야자 학생용 오픈채팅방 하나에 공지처럼 보내거나 감독 선생님 방으로 보내는 방식이 됩니다.

## 3. 웹훅 (서버 모드)

감독 화면 설정의 "알림 웹훅 주소"에 주소를 넣으면 배정마다 위 이벤트 하나를 JSON으로 POST합니다. 시연 모드에서도 브라우저가 보내 보기는 하지만, 받는 쪽이 CORS를 허용하지 않으면 도착 여부를 확인할 수 없습니다.

## 참고: 카카오 알림톡

학생 휴대폰 번호로 직접 카카오톡을 보내는 공식 방법은 알림톡입니다. 카카오 비즈니스 채널과 발송 대행사 계약이 필요하고 건당 요금이 들어서, 학교 차원에서 실제로 도입할 때 검토할 방법입니다.
