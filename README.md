# 자기주도학습실 좌석 배정 키오스크

야간자율학습 시간에 학생이 태블릿 키오스크에서 학생증 바코드(또는 학번)로 자리를 배정받고, 감독 선생님은 누가 어디에 앉았는지와 누가 아직 안 왔는지를 한 화면에서 확인하는 시스템입니다. 다이나믹스 1조 탐구 결과물입니다.

## 화면

| 주소 | 용도 |
| --- | --- |
| `index.html` | 키오스크. "카메라 켜기"를 눌렀을 때만 카메라가 켜지고, 학번을 직접 입력해도 됩니다. 자리 선택, 자리 변경, 외출과 돌아옴, 반납을 할 수 있습니다. 오른쪽 위 [감독] 버튼으로 감독 화면에 갑니다. |
| `admin.html` | 감독 화면. 아래 "감독 화면 기능"을 보세요. PIN은 숫자 키패드로 누르며 처음 값은 `.env`의 `ADMIN_PIN`(기본 `0000`)입니다. |
| `me.html` | 배정이 끝나면 키오스크에 뜨는 QR을 휴대폰으로 찍었을 때 열리는 "내 자리" 화면입니다. |
| `cards.html` | 명단의 학번을 Code 128 바코드로 찍은 시연용 카드 인쇄 페이지(A4 8장). |

## 감독 화면 기능

- **좌석**: 배치도에서 누가 어디 앉았는지, 방금 들어온 학생, 외출 중인 자리를 봅니다. 학생을 누르면 자리 옮기기, 외출, 조퇴, 반납을 처리하고, 빈자리를 누르면 고장 난 자리를 막거나 다시 엽니다.
- **안 온 학생**: 야자 신청했는데 안 온 학생을 반별로 보고 바로 자리를 정해 줍니다. 외출 중인 학생, 신청 안 하고 온 학생도 따로 보입니다.
- **명단**: 학년, 반, 신청 여부로 걸러 보고 한 명씩 더하기, 고치기, 지우기, 야자 신청 켜고 끄기를 합니다. 걸러 낸 학생을 한 번에 신청, 신청 취소, 지우기(졸업생 정리 등)도 됩니다.
  - **명단 불러오기**: 엑셀(.xlsx), CSV(UTF-8 또는 엑셀 기본 저장 형식인 EUC-KR), 엑셀에서 복사한 표 붙여 넣기. 머리글(학번, 이름 또는 성명, 야자신청)을 알아서 찾고, 학번 칸 없이 학년, 반, 번호 칸만 있어도 학번(학년 1자리 + 반 2자리 + 번호 2자리)을 만듭니다. 문제 있는 줄은 몇 번째 줄인지 보여 주고 빼고 불러옵니다. 불러오는 방식은 명단 전체 바꾸기, 지금 명단에 더하기, 야자 신청만 바꾸기(학번만 있는 신청자 명단) 중에서 고릅니다. 예전 엑셀(.xls)은 .xlsx나 CSV로 다시 저장해서 올립니다.
  - 명단 내려받기, 빈 양식 내려받기, 시연용 바코드 카드 만들기.
- **기록**: 오늘 시간대별 입실 그래프, 반별 출석, 배정과 외출 기록. 서버 모드에서는 날마다 기록이 `data/history/날짜.json`으로 쌓이고, 날짜별 기록과 기간 출석부(학생마다 날짜별 O, X, 조퇴)를 CSV로 내려받습니다.
- **설정**: 야자 시간과 요일, 시연 모드, 알림 주소, PIN 바꾸기(지금 PIN 확인 후 새 PIN 두 번), 자동 잠금(안 만지면 잠그기), 백업 내려받기와 되돌리기, 오늘 자리 비우기.

### 보안

- 서버는 PIN을 scrypt 해시로만 저장하고, 로그인하면 12시간짜리 세션을 줍니다. PIN을 바꾸면 다른 기기의 로그인은 모두 풀립니다.
- PIN을 5번 틀리면 30초, 그 뒤로 틀릴 때마다 기다리는 시간이 두 배(최대 15분)가 됩니다.
- 감독 화면은 오른쪽 위 [잠그기]로 바로 잠그거나, 설정한 시간 동안 안 만지면 저절로 잠깁니다.
- PIN을 잊으면 서버에서 `./deploy.sh reset-pin 1234`를 실행하고 새 PIN으로 로그인합니다.

## 운영 규칙

- 아침과 점심은 자유석이라 키오스크를 쓰지 않고, 야간자율학습 시간(기본 18:00~22:30)에만 배정합니다.
- 야자 하는 요일(기본 월~금)이 아닌 날에는 배정을 받지 않습니다. 시연 모드를 켜면 시간과 요일에 상관없이 배정할 수 있습니다. 기본값은 켜짐입니다.
- 날짜가 바뀌면 그날 기록을 보관하고 좌석을 비웁니다.
- 외출하면 자리는 그대로 두고 외출 중으로 표시합니다. 감독이 조퇴로 처리하면 자리가 비고 기록에 조퇴로 남습니다.
- 한 학생은 한 자리만 쓸 수 있고, 다른 자리를 고르면 이동으로 처리됩니다.

## 두 가지 실행 방식

### 1. 시연 모드 (GitHub Pages, 서버 없음)

`public/` 폴더를 그대로 정적 호스팅합니다. 데이터는 그 태블릿 브라우저에 저장되고, 키오스크와 감독 화면은 같은 태블릿에서 탭을 바꿔 봅니다. 한 번 열어 두면 와이파이가 끊겨도 동작합니다. 카메라는 HTTPS에서만 켜지는데 GitHub Pages는 HTTPS라 그대로 됩니다.

### 2. 서버 모드 (Docker, OCI에서 테스트한 뒤 UNO Q로)

여러 태블릿과 감독 기기가 같은 좌석 현황을 봅니다. 좌석 서버(Node 내장 모듈만 사용)와 HTTPS를 붙여 주는 Caddy가 한 묶음으로 뜹니다. 갤럭시탭 크롬은 HTTPS에서만 카메라를 켜 주기 때문에 HTTPS가 필수입니다.

```sh
git clone https://github.com/dev-jihoon/self-study-room-kiosk.git
cd self-study-room-kiosk
./deploy.sh oci          # OCI: 공인 IP로 https://<IP>.sslip.io 주소와 정식 인증서를 자동으로 만듦
./deploy.sh lan          # UNO Q: 학교 와이파이 IP로 https://<IP> (자체 인증서)
./deploy.sh npm          # Nginx Proxy Manager가 있는 서버: 좌석 서버만 띄워 NPM 네트워크에 붙임
./deploy.sh logs         # 로그
./deploy.sh stop         # 내리기
./deploy.sh reset-pin 1234  # 감독 PIN을 잊었을 때
```

- Nginx Proxy Manager(NPM)가 이미 80, 443을 쓰는 서버에서는 `npm` 모드를 씁니다. Caddy는 띄우지 않고, 좌석 서버 컨테이너(`study-room-kiosk`)를 NPM과 같은 도커 네트워크에 붙입니다. `.env`에 NPM 관리자 계정(`NPM_EMAIL`, `NPM_PASSWORD`, 특수문자가 있으면 작은따옴표로 감싸기)을 넣어 두면 `scripts/npm-proxy-host.sh`가 NPM API로 Proxy Host(`http://study-room-kiosk:8080`, Let's Encrypt 인증서, HTTPS 강제)를 만들어 줘서 관리 화면을 열 필요가 없습니다. 도메인은 `KIOSK_DOMAIN`, 비워 두면 `<공인IP>.sslip.io`입니다.
- OCI에서는 콘솔의 보안 목록(Security List)에 TCP 80, 443 수신 규칙을 추가해야 합니다. Ubuntu 이미지는 서버 안 iptables도 막혀 있어서 `./deploy.sh oci --open-firewall`로 같이 열 수 있습니다.
- 인증서 발급에 80번이나 443번 포트가 밖에서 열려 있어야 합니다. 이미 다른 프로그램이 쓰고 있으면 먼저 정리하세요.
- UNO Q(lan)에서는 태블릿이 처음 접속할 때 인증서 경고가 나옵니다. "고급 > 계속"을 누르면 카메라까지 동작합니다.
- 감독 PIN, 시연 모드, 알림 토큰은 `.env`에서 바꿉니다(`.env.example` 참고). 데이터는 `data/state.json`, 명단은 `data/roster.csv`(학번,이름,야자신청)를 두면 처음 실행 때 씁니다.
- Docker 없이: `node server/server.js` (환경 변수 `PORT`, `DATA_DIR`, `ADMIN_PIN`, `DEMO_MODE`, `EVENTS_TOKEN`). 동작 확인은 `npm test`.

## 배정 알림

배정되면 학생에게 자리를 알려 주는 방법은 세 가지입니다. 자세한 내용은 [docs/notifications.md](docs/notifications.md)에 있습니다.

1. **QR 내 자리 확인** (지금 동작): 배정 완료 화면의 QR을 휴대폰으로 찍으면 자리 번호와 배치도가 뜹니다.
2. **카카오톡 봇 연동** (서버 모드): 봇이 `GET /api/events?since=…`로 새 배정을 가져가 메시지를 보냅니다.
3. **웹훅** (서버 모드): 감독 화면 설정에 주소를 넣으면 배정마다 JSON을 POST합니다.

## 구조

```
public/
  index.html admin.html me.html cards.html
  js/core.js       배정 규칙. 브라우저와 서버가 같이 씀
  js/store.js      서버가 있으면 api/, 없으면 브라우저 저장소
  js/tablefile.js  명단 파일 읽기 (xlsx, CSV EUC-KR/UTF-8)
  js/seatmap.js    좌석 배치도 그리기
  js/scanner.js    카메라 바코드 인식 (BarcodeDetector, 없으면 ZXing)
  data/layout.json 좌석 배치 (26학년도 2차 좌석표 기준 107석, 11줄, 기둥 2개)
  data/roster.json 시연용 명단 1080명 (학번 10101~31036, 3학년 10반 36명, 영어 이름, 야자 신청 102명)
  vendor/          ZXing, qrcode-generator (MIT), Pretendard 글꼴 (SIL OFL 1.1)
  js/code128.js    시연용 카드 바코드 (Code 128)
server/server.js   서버 모드
Caddyfile          HTTPS 앞단 (deploy.sh가 주소를 채움)
docker-compose.npm.yml  NPM 서버용 (Caddy 없이 NPM 네트워크에 붙임)
deploy.sh          OCI, UNO Q 배포 스크립트
```

좌석 배치를 바꾸려면 `public/data/layout.json`만 고치면 됩니다. 숫자는 좌석 번호, `"P"`는 기둥, `null`은 빈칸입니다.
